# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

The **Hanlin Software** studio site, live at https://hanlinsoftware.com as a **Cloudflare Worker with static assets** (Workers Builds, Git-connected; production branch `main`). No build system or bundler — files are served as-is.

**Only `public/` is published** (`wrangler.toml` → `[assets] directory = "./public"`; Workers Builds runs `wrangler deploy`). Never put repo internals (docs, notes, package files) in `public/`. The root `index.html` / `404.html` are GitHub Pages redirect stubs that send `cph5236.github.io/<path>` to `hanlinsoftware.com/<path>` — not part of the live site.

```bash
python3 -m http.server 8080 -d public   # preview
python3 tools/check_site.py             # broken links, missing alt, leaked internals → must PASS
```

## Architecture

| Page | Files |
|---|---|
| `/` studio home, product bands | `public/index.html`, `assets/css/products.css` |
| `/brewery-simulator/`, `/heap/`, `/simple-weather/` | `assets/css/product-page.css` (shared layout, `--p-*` tokens) + `product-<key>.css` (theme) |
| `/about/` Connor's portfolio + CV modal | `assets/css/custom.css` (`.about-page` overrides), `assets/js/nav.js` |
| `/ApiBuilder/api-builder.html` | `assets/js/api-builder.js`, `api-storage.js`, `assets/css/api-builder.css` |

- **Studio frame** (`assets/css/studio.css`): `--studio-*` tokens, accent amber `#f5b43a`, dark only (no theme toggle). Logo is text: `]-[anlin.software_` in JetBrains Mono (`.studio-logo`). Brand images in `assets/img/brand/` are generated by `tools/make_brand.py`.
- **Nav and footer markup is duplicated in every page** (no JS includes) — change all pages together. Nav: logo · Products (`/#products`) · About · Contact (mailto `hanlinsoftwareSWS@gmail.com`).
- **Each product keeps its own look**; colors/fonts come from that product's repo (BrwerySim `docs/design/ui-style.md`, heapgame.com CSS, SimpleWeatherService `src/index.css`).
- **Steam URL** for Craft Brewery Simulator: `STEAM_URL` in `assets/js/steam.js` (empty = "Coming soon to Steam").
- **Product art**: `tools/fetch_assets.py` (BrwerySim is private + Git LFS; script uses `gh` + LFS batch API). Keep images ≤ 300 KB.
- **Bootstrap 5.3.9** is vendored in `assets/vendor/bootstrap/` (copied from `node_modules` after `npm install`); only About and API Builder load it.
- **CSP** in `public/_headers`: `script-src 'self'` — no inline `<script>` or `on*=` attributes.
- Use root-absolute URLs (`/assets/...`) in pages.

## API Builder data model

Folders array containing requests, each with id, name, method, url, headers, params, body (localStorage key `apiBuilderData`). Escape any user/imported value before putting it in `innerHTML` (`escapeHtml` / `escapeAttr`).

## Model Selection Strategy

Claude Code supports running different Claude models for different tasks. Route work to maximize efficiency:

- **Opus** — Architecture, planning, design decisions. Use when the task requires weighing multiple approaches or designing a complex feature.
- **Sonnet** — Implementation, code review, refactoring. Use for writing and modifying code with full context.
- **Haiku** — File searches, formatting, simple edits, mechanical tasks. Use for grunt work; keeps main session lean and token burn low.

**For subagents:** File exploration and codebase searches naturally delegate to Haiku. The planning phase (Opus) is upfront investment that makes implementation (Sonnet) straightforward.
